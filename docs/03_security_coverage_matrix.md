## E. Extra protections (not separate course topics)

| Protection | Where | Why |
|------------|-------|-----|
| Session cookie `HttpOnly`, `SameSite=Lax`, 30‑minute lifetime; random `SECRET_KEY` unless set in the environment | `config.py`, `app.py` | Harder to steal or forge the session |
| One‑time checkout token in the pay form | `orders.py` `checkout()`, `pay()` | Stops double payment and also stops another site from submitting the payment form |
| Data‑changing actions are POST only | all blueprints | A link or image on another site cannot trigger them with a GET |
| No `?next=` redirect after login | `security.py` `login_required()` | Prevents open redirects |
| Coupon guessing limit (10 wrong codes / 10 min per user) | `coupons.py` `apply_coupon()` | Stops Intruder from finding codes |
| Newsletter: confirmed accounts only, one coupon per user **and** per email | `coupons.py` `newsletter()` | No coupon farming |
| Hidden products never shown or sold; products are hidden, never deleted | `catalog.py`, `cart.py`, `admin.py` `toggle_product()` | Old orders keep their history |
| Token use, TOTP step and credit/stock updates are atomic (`… AND used_at IS NULL`, `… AND totp_last_step < ?`, `… AND stock >= ?`) | `auth.py`, `orders.py` | Two requests at the same moment cannot both succeed |
| New admin's TOTP secret shown once, `Cache-Control: no-store`, never in a flash/cookie or the audit log | `admin.py` `change_role()` | The secret does not leak |
| `PRAGMA foreign_keys = ON`; money as integer cents | `db.py`, `schema.sql` | Data stays consistent; no rounding tricks |
| Outbox file names never contain user input | `auth.py` `send_email()` | No path tricks through the email address |
